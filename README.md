# Web Project

Monorepo que unifica el frontend y el backend del mismo proyecto.

## Estructura

- `frontend/`: aplicación React proveniente de `Front_Web_Project`.
- `backend/`: API NestJS proveniente de `Back_Web_Project`.

## Instalación

```bash
npm run install:all
```

## Desarrollo

Frontend:

```bash
npm run frontend
```

Backend:

```bash
npm run backend
```

## Build

```bash
npm run build
```

Los repositorios originales se mantienen intactos mientras se valida esta rama de integración.
